# Quick Start Guide

## Step 1: Get a Script Executor
- **Recommended Free**: Krnl, SOLX
- **Premium**: Synapse X, Script-Ware
- Download and install for your PC

## Step 2: Copy the Script
1. Open `KickALuckyBlock.lua` in this repository
2. Select all content (Ctrl+A)
3. Copy it (Ctrl+C)

## Step 3: Execute in Game
1. Launch Roblox and join "Kick A Lucky Block"
2. Open your script executor
3. Paste the script into the code area
4. Click "Execute" or press F9

## Step 4: Configure Features

### For Auto Train:
1. Go to "🏋️ Auto Train" tab
2. Toggle "Enable Auto Train" ✓
3. (Optional) Adjust "Train Speed" slider
4. Toggle "Start Auto Train Loop" ✓

### For God Mode:
1. Go to "❤️ God Mode" tab
2. Toggle "Enable God Mode (Inf Health)" ✓
3. You now have infinite health!

### For Auto Collect:
1. Go to "💰 Auto Collect" tab
2. Make sure you're in your base
3. Toggle "Enable Auto Collect" ✓
4. Toggle "Start Auto Collect Loop" ✓
5. Adjust range with slider if needed

### For Auto Upgrade:
1. Go to "⬆️ Auto Upgrade" tab
2. Have enough money for upgrades
3. Toggle "Enable Auto Upgrade" ✓
4. Toggle "Start Auto Upgrade Loop" ✓
5. Or click "Upgrade All Brainrots" for one-time upgrade

## Common Issues & Fixes

**"WindUI didn't load"**
- Your executor doesn't support WindUI (or configure the WindUI URL in the script)
- Try a different executor

**"Auto Train not clicking button"**
- Make sure the ×2 button is visible
- The button color might be different (check CONFIG.lua)

**"God Mode not working"**
- Toggle it OFF then back ON after respawning
- Your health might be capped by the game

**"Auto Collect does nothing"**
- Make sure money objects exist in your game
- Check their names match what's in the script

**"Script crashed"**
- Click "Stop All Scripts" first
- Re-execute the script

## Tips for Best Results

✅ **DO:**
- Disable God Mode in multiplayer areas
- Stop features when AFK to avoid detection
- Keep executor updated
- Use reasonable delay settings

❌ **DON'T:**
- Leave features running 24/7 (ban risk)
- Use in competitive/multiplayer areas
- Modify game files directly
- Share your executor with others

## Performance Settings

- **Fast Mode**: Speed 0.05, Delay 0.1 (CPU intensive)
- **Balanced**: Speed 0.1, Delay 0.5 (recommended)
- **Safe Mode**: Speed 0.2, Delay 1.0 (less detection risk)
